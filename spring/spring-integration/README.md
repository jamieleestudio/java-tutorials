# Spring Integration 示例

Spring Integration 是 Spring 生态的企业集成框架（EIP 企业集成模式实现），
通过通道（Channel）、适配器（Adapter）、网关（Gateway）将外部系统
（MQTT/Kafka/JMS/文件/HTTP...）与 Spring 应用解耦。
