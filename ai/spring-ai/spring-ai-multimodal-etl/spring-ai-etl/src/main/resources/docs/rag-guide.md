# RAG 指南

RAG（Retrieval-Augmented Generation，检索增强生成）通过在生成前检索相关知识来提升大模型的回答质量。

## 为什么需要 RAG

大模型的知识截止到训练数据，无法覆盖私有或新产生的信息。RAG 把外部文档注入生成过程，让模型基于事实回答，减少幻觉。

## RAG 的组成部分

RAG 通常包含三个环节：

1. **入库（Indexing）**：把文档读取、切分、嵌入为向量，写入向量数据库。
2. **检索（Retrieval）**：把用户问题嵌入为向量，用相似度在向量库中查找相关文档。
3. **生成（Generation）**：把检索到的文档作为上下文拼入 prompt，让模型生成回答。

## 与微调的区别

微调改变模型的权重，成本高、周期长；RAG 不改模型，只注入上下文，成本低、可实时更新。两者可以结合使用。
